개인정보처리방침

Latch — Private Gallery · 최종 수정 2026년 10월 1일

Latch는 전부 기기 안에서만 동작하는 비공개 사진·동영상 보관함입니다. 이 방침은 앱이 사용자의 정보를 어떻게 다루는지 설명합니다. 거의 모든 항목의 답이 "아무것도 하지 않는다"이기 때문에 내용이 짧습니다.

요약 Latch는 어떤 개인정보도 수집하지 않습니다. 계정, 분석 도구, 광고, 추적 기능이 없으며, 사용자에 관한 정보를 전달받는 제3자 서비스도 없습니다. 사진과 동영상은 사용자 기기의 앱 내부 저장 영역에만 보관되며, 앱이 이를 외부로 전송하는 일은 없습니다.

수집하는 정보

없습니다. 개발자는 사용자나 앱 사용 내역에 관한 어떤 정보도 받지 않습니다. 구체적으로 이 앱에는 분석 프레임워크, 크래시 리포팅 서비스, 광고 식별자, 소셜 로그인이 없고, 개발자가 운영하는 서버에 접속하는 코드도 없습니다.

사진과 동영상

가져온 미디어는 다른 앱이 읽을 수 없는 앱 전용 저장 영역(iOS 애플리케이션 샌드박스)으로 복사됩니다. 전달받은 원본 바이트를 그대로 저장하며, 앱은 재인코딩을 하지 않습니다.

이 저장 영역은 iCloud 및 iTunes/Finder 기기 백업에서 제외되도록 표시됩니다. 비공개 보관함이 다른 곳에 보관될 수 있는 백업으로 복사되지 않게 하려는 의도적인 선택이며, 아래와 같은 중요한 결과를 함께 가져옵니다.

보관함은 백업되지 않습니다 앱 저장 영역이 백업에서 제외되므로, Latch를 삭제하거나 기기를 초기화하거나 새 기기로 옮기면 앱에 보관된 모든 내용이 영구적으로 소실됩니다. 다른 어디에도 사본이 없고, 개발자도 복구할 수 없습니다. 잃어버리면 안 되는 자료는 앱의 내보내기 기능으로 따로 사본을 보관하십시오.

비밀번호

Latch는 사용자가 정한 숫자 비밀번호로 보관함을 보호합니다. 비밀번호 자체는 저장되지 않습니다. 앱은 솔트를 더한 암호학적 해시만 iOS 키체인에 저장하고, 이후 입력값을 그 해시와 비교합니다.

복구 수단, 재설정 링크, 우회 경로는 없습니다. 비밀번호를 잊으면 사용자도 개발자도 보관함을 열 수 없습니다. 서버와 계정이 없는 앱이기 때문에 생기는 결과입니다 — 물어볼 상대가 존재하지 않습니다.

Face ID와 Touch ID

생체 인증 잠금 해제를 켜면 인증은 iOS가 직접 수행합니다. 앱은 인증 성공 여부만 시스템에 묻고 예·아니오만 받습니다. 지문과 얼굴 데이터는 앱에 전달되지 않으며, iOS가 앱에 노출하지 않으므로 전달될 수도 없습니다.

선택 기능: 자동 삭제

Latch에는 비밀번호를 연속으로 일정 횟수 이상 틀리면 앱의 모든 데이터를 삭제하는 설정이 있으며, 기본값은 꺼짐입니다. 사용자가 직접 켠 경우에만 동작합니다. 동작할 경우 삭제는 즉시 이루어지며 되돌릴 수 없습니다.

앱이 요청하는 시스템 권한

사진 라이브러리
읽기 권한은 사용자가 직접 선택한 항목을 앱으로 복사할 때만 사용합니다. 앱이 스스로 사진 라이브러리를 탐색하거나 색인하지 않습니다. 쓰기 권한은 사용자가 사진 앱으로 내보내기를 실행하는 시점에만 요청합니다.
로컬 네트워크
아래에 설명한 선택 기능인 웹서버에만 사용합니다. 앱이 네트워크를 스캔하거나 다른 기기를 탐색하지 않습니다.
Face ID
사용자가 켠 경우에만, 앱 잠금 해제에만 사용합니다.

이 가운데 어떤 권한을 거부해도 나머지 기능은 그대로 동작하며, 해당 권한이 필요한 기능만 사용할 수 없게 됩니다.

로컬 웹서버

Latch에는 같은 Wi‑Fi 네트워크의 컴퓨터에서 보관함을 열어보고 파일을 주고받을 수 있는 선택 기능이 있습니다. 이 기능을 켜면:

  • 로컬 네트워크에서만 응답합니다. 인터넷에서는 접근할 수 없고, 앱이 포트 포워딩이나 중계 서버를 설정하지도 않습니다.
  • 앱이 보여주는 사용자 이름과 비밀번호를 요구하며, 반복된 로그인 실패를 제한합니다.
  • Latch가 화면에 열려 있을 때만 동작합니다. 다른 앱으로 전환하거나 기기를 잠그면 중지됩니다.
  • 개발자나 제3자에게 전송되는 것은 없습니다. 관여하는 주체는 사용자의 기기와 접속한 컴퓨터뿐입니다.

로컬 네트워크 구간의 통신은 암호화되지 않습니다. 가정이나 개인 네트워크에서는 다른 기기 간 전송과 같은 수준이지만, 공용이나 신뢰할 수 없는 Wi‑Fi에서는 이 기능을 켜지 마십시오.

결제

Latch는 추가 기능을 해제하는 일회성 인앱 구매를 제공합니다. 결제는 전부 Apple이 처리합니다. 개발자는 결제 정보, Apple 계정, 이름을 전혀 볼 수 없습니다. 앱은 Apple의 온디바이스 영수증 검증으로 구매 여부만 확인하며, 구매 정보를 개발자나 다른 서버로 보내지 않습니다.

아동

Latch는 아동을 대상으로 하지 않으며, 아동을 포함해 누구에게서도 데이터를 수집하지 않습니다.

제3자 코드

앱에는 오픈소스 HTTP 서버 라이브러리 FlyingFox(MIT 라이선스)가 포함되어 있으며, 웹서버 기능의 일부로 기기 안에서 동작합니다. 서비스가 아니라 소프트웨어 구성 요소이므로 어디로도 데이터를 보내지 않고, 제작자도 사용자에 관한 정보를 받지 않습니다.

방침 변경

이 방침이 바뀌면 상단 날짜를 갱신한 새 버전을 같은 주소에 게시합니다. 앱이 수집하는 정보가 없으므로, 변경은 실제 처리 방식의 변화가 아니라 설명의 보완일 것으로 예상합니다.
